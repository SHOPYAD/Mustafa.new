# TicketIssuanceNotify_V2 - PKFARE Flight Buyer API

## TicketIssuanceNotify_V2

## 1 Function

Buyer partners should provide a webhook/URL based on HTTP/HTTPS protocol to PKFARE for push ticket numbers and airlines PNR. PKFARE will push ticket numbers when the tickets are issued. In another case, if the request was rejected, a rejected reason would be provided.

## 2 Versioning

| Version | Sandbox Invoking Address | Update |
| --- | --- | --- |
| TicketingNumPush | This address is provided by the customer. |  |
| TicketingNumPush_V2 | This address is provided by the customer. | Add information about voiding tickets. |
| TicketingNumPush_V3 | This address is provided by the customer. | Add PNR list for more accurate mapping relations between airlines PNR and pax/flight. |
| TicketIssuanceNotify | This address is provided by the customer. | Support infant ticket. More parameters are provided for change orders. |
| TicketIssuanceNotify_V2 | This address is provided by the customer. | Support ticketing fasilure screnarios with reasons |

## 3 Character Encoding

The character code of this API is UTF-8.

## 4 Request

The request is sent by PKFARE API. Requesting method would be POST.

| parentOrderNum | String | Parent order number of this order | 96848725690201 |

| buyerOrder | String | BuyerOrder | 1234567 |
| data | Object | Include remark field for reference | - |
| passengers |  |  |  |
| passengerIndex | String | Passenger sequence no. Positive and continuous integer starting from 1. If this booking contains infants. The passengerIndex is all the same as those in the booking request. If no infant, the passengerIndex(s) are generated by the system automatically. | 3 |

\', like 9991234567890/9991234567891 | 1122334455667 |

| airPnr | String | Airline PNR | EDTCZP |

| ticketNum | String | Ticket number | 9991234567890 |
