# التقنية والمشاريع التي تختصر العمل
هذه توصيات للإدماج بعد جرد المشروع؛ النموذج المرفق لا يتطلبها للتشغيل.

## واجهة الشبكة
[React Flow / xyflow](https://github.com/xyflow/xyflow) لبناء العقد والحواف والتفاعل داخل React ، مع أشكال وحواف مخصصة. [دليل التخطيطات](https://reactflow.dev/learn/layouting/layouting) يشرح بدائل التخطيط؛ المكتبة لا تعطي الشكل السينمائي تلقائيًا.
استفد من أمثلة Custom Nodes / Animated Edges / Save and Restore ، ثم ضعها خلفواجهات بيانات المشروع. لا تفترض أن أمثلة Pro المدفوعة ضمن الرخصة المجانية.
[ELK.js](https://github.com/kieler/elkjs) لحساب مواضع DAG والموانئ. ضعه في Worker عندما يصبح التخطيط مكلفًا، معإلغاءنتيجةقديمة إذا تغير graph version. لا تفرض إعادةتخطيطشامل بعد كلحدث.

## المؤثرات والحضور
[PixiJS](https://pixijs.com/) ومحركه [على GitHub](https://github.com/pixijs/pixijs) طبقة 2D للجسيمات والخلفيات؛ DOM يبقى للنماذج والنصوص. راجع LICENSE فيالإصدار المثبت.
[Three.js](https://threejs.org/) و[المستودع](https://github.com/mrdoob/three.js) للحضور ثلاثي الأبعاد 20 ، لا لكللوحة. النموذج التشريحي، مواد الخطوط، point sampling ، النواة، الـ bloom وأثرالصوت عمل فني/هندسي مستقل.
لا تُجمع ReactFlow و Pixi و Three كعناصرمتوازية تدير نفسالأحداث. graphstore واحد؛ renderer يقرأ؛ hit-testing له مالك واحد.
Web Audio يحلل صوتًا بعد إذن، أما speechSynthesis المحلي فلا يمنح هنا تحليل PCM لخرجه. التكامل الحقيقي يحتاج مصدرخرج قابلًا للتحليل وتوقيتًا معلومًا.
لا يُشترط شراءمكتبة لضمانالجودة، ولا يمنعك استخداممكتبة مفتوحة من الحاجةلتصميمأصولمخصصة.

## اختبارات
[Playwright snapshots](https://playwright.dev/docs/test-snapshots) لمراقبة الفروق بعد تثبيت بيئة الرندرة والمرجعالمعتمد. اختلاف المتصفح والنظام والخطوط قد يغير اللقطة.
[webServer](https://playwright.dev/docs/test-webserver) لتشغيلهدفمحلي، و[Clock](https://playwright.dev/docs/clock) لضبطالوقت فياختبارات تحتاجه. النموذج هنا يستخدم test mode وحركةثابتة.
[Pixelmatch](https://github.com/mapbox/pixelmatch) فيالمقارنة المرفقة؛ threshold0 و includeAA لضبطمعيار exact. النجاحالبصري الفني يحتاج مراجعةولا يستنتج مننسبةاختلافالبيكسلات.

## إدخال المكتبات إلى المستودع
1. اكتشفإطارالمشروع، مديرالحزم والنسخالحالية. لا تستبدله كله.
2. أنشئفرعًا واحفظ حالةعملالمستخدم دون reset.
3. جرّبالمكتبةالمختارة فيمسار featureflag واحد بمكوناتالمشروع.
4. ثبّتنُسخًامتوافقةفي lockfile ؛ لا تثبت latest عمياءولا تنسخ node_modules.
5. وثقالرخصو NOTICE وأصولالخطوطوالنماذجوالصور المستعملة.
6. جرّبالعقدةوالمساروالتحميلالعالي، ثموسّعإلىالمجالاتحسبالمراحل.
7. انتقلللإنتاج فقطبعداختباراتالبياناتوالعزلوالاعتماد.
لايوجد repo عام نؤكدأنهينسخمنصتكمبمافيها Backend ؛ المصادرأدواتبناء وليستمنتجًا مطابقًا.
