# القرارات البصرية والعقد الفني — التوثيق والمواصفات الشاملة (الشاشات 01 إلى 20)

## 1. فلسفة التصميم والهوية السيبرانية
- الهوية البصرية تعتمد نظام الـ Cybernetic Sci-Fi HUD مع لوحة ألوان دقيقة:
  - التوهج السماوي (Cyan `#27dff4`) للتنقل والعقد والنشاط السيبراني والوصلات الكهربائية.
  - النواة الذهبية/الكهرمانية (`#eec66d` و `#ffb54c`) للوكيل المشرف العام والمحاور الحيوية ومسارات التأكيد.
  - النيون القرمزي/البنفسجي (`#a855f7` و `#ec4899`) للذكاء الاصطناعي الإبداعي ونماذج الفيديو والأتمتة المتقدمة.
  - الزمردي الأخضر (`#10b981`) للعمليات المكتملة وحالة الخوادم النشطة ونتائج الفحص الإيجابية.
  - التنبيه القرمزي (`#ef4444`) لأخطاء الشبكة، الإلغاءات، وتحذيرات الامتثال الأمني.
  - الخلفية الفضائية المظلمة العميقة (`#020c17` / `#050d1a`) مع طبقة شبكية هولوجرافية دقيقة (HUD Grid) وجسيمات نجمية متلألئة.
  - النوافذ الشفافة الزجاجية (Glassmorphic HUD Panels) بخلفية `rgba(6, 18, 36, 0.75)` وحدود مشعة رقيقة `rgba(39, 223, 244, 0.2)` وضبابية `backdrop-filter: blur(16px)`.

## 2. إدارة الطبقات والنوافذ ومستويات العمق (L0 .. L3)
- الطبقات الصارمة:
  - Z-0: الخلفية الفلكية المعتمة مع التوهج الشعاعي المركزي.
  - Z-1: الشبكة الهندسية الهولوجرافية ودوائر الرادار الإشعاعية.
  - Z-2: روابط العلاقات المنحنية (Bézier edges) مع نبضات ضوئية متحركة (flowing photon particles).
  - Z-3: العقد التشغيلية والمجموعات والعناقيد السداسية (Hexagonal Pods).
  - Z-4: عناوين وبطاقات العقد والمقاييس اللحظية (Telemetry Chips).
  - Z-10: النوافذ العائمة القابلة للسحب والتحجيم والتثبيت والتصغير.
  - Z-20: شريط التحكم الصوتي السفلي وقرص الموجات التفاعلية.
  - Z-25: الشريط العلوي الثابت مع شارات الحالة الحية ومبدل الشاشات ومستوى التوسع (`L0..L3`).
  - Z-50: النوافذ المنبثقة للتنفيذ الفعلي لأدوات MCP ومحدد الشاشات العشرين ومودال الصورة المرجعية.

## 3. المواصفات البصرية المرجعية للشاشات العشرين (01 — 20)
1. **Screen 01 (الأطلس العصبي الشامل)**: تخطيط شعاعي دائري كامل يربط النواة الإدارية بـ 11 نطاقاً رئيسياً مع خطوط اتصال نيونية مشعة.
2. **Screen 02 (التوسع التراكمي الشامل)**: مصفوفة الشجرة الشاملة مع تفرعات المستوى العميق (L0: المنظومة -> L1: النطاق -> L2: الخدمة -> L3: الإجراء التنفيذي).
3. **Screen 03 (الحجوزات والإلغاء والتقييمات)**: مخطط تدفق إجرائي DAG يوضح مسار دورة حياة الحجز من الطلب، التحقق، المورد، الإصدار، حتى الإلغاء والاسترداد.
4. **Screen 04 (الرحلات وموزعو GDS)**: لوحة إلكترونية دوائرية تحاكي رادار الطيران اللحظي وربط أنظمة التوزيع العالمية (Amadeus/Sabre/Travelport).
5. **Screen 05 (الفنادق وبنوك الأسرّة)**: خريطة موائل دائرية تحيط بها بنوك الأسرة الكبرى ومستويات التوافر ومحرك الفنادق المحلي.
6. **Screen 06 (النقل والجولات والأسطول)**: خريطة جغرافية ليلية سيبرانية لأسطول المركبات والجولات السياحية وتتبع الحركة الفورية.
7. **Screen 07 (محتوى الموقع والتطبيقات)**: لوحة تحكم CMS مزدوجة مع محاكي شاشات الأجهزة (موبايل، تابلت، ديسكتوب) ومولد المقالات الذكي.
8. **Screen 08 (العملاء وخدمة العملاء 360)**: بطاقة عميل متكاملة (ملف، ولاء، حجوزات سابقة) مع واجهة محادثة شات سيبرانية نشطة وتذاكر الدعم.
9. **Screen 09 (النشر متعدد القنوات والفيديو)**: استوديو الوسائط المتعددة وجدولة 7 أيام ومصفوفة محتوى ريلز/تيك توك/يوتيوب ومحركات الفيديو.
10. **Screen 10 (الحملات والتسويق والإعلانات)**: قمع تسويقي متدرج (Funnel) مع مؤشرات العائد على الإنفاق (ROAS) وشريط تحكم ميزانية الذكاء الاصطناعي.
11. **Screen 11 (غرفة الوكلاء المتعددين ومصفوفة MCP)**: مصفوفة الوكلاء المتخصصين الستة، بطاقات الحالة العصبية، ومصفوفة الـ 21 خادم MCP والـ 88 أداة.
12. **Screen 12 (استوديو الأتمتة ومحرك التدفقات)**: مخطط شرطي تنفيذي (Trigger -> Logic/Condition -> Action -> Timeout) مع مقاييس النجاح وزمن التنفيذ.
13. **Screen 13 (المالية والفوترة والتسوية)**: سجل قيود محاسبية زجاجي، مؤشرات تدفق سيولة، ومعاينة مستندات PDF للفواتير الإلكترونية.
14. **Screen 14 (إعادة البيع وشبكة B2B)**: خريطة شبكة الشركاء الموزعين، تراخيص White-Label، وتخصيص عمولات الوكلاء الفرعيين.
15. **Screen 15 (الامتثال والخصوصية والأمان)**: فاحص سياسات الخصوصية، رادار انتهاكات الأمان، وسجل التدقيق والامتثال لنظام GDPR/الأنظمة المحلية.
16. **Screen 16 (الإعدادات والتكاملات التقنية)**: لوحة تكوينات الخادم، بوابات الدفع، فحص اتصال SMTP المباشر، ومفاتيح API المشفرة.
17. **Screen 17 (القرص الصوتي وحالات الوكيل الست)**: قرص صوتي ذبذبي مركزي يعرض الحالات (خامل، استماع، تفكير، توليد، تنفيذ، تنبيه) وخط أنابيب المعالجة.
18. **Screen 18 (إدارة النوافذ والمساحات)**: معمل النوافذ العائمة التفاعلية، دعم الإرساء (Docking)، التحجيم، وتعدد الشاشات المنبثقة.
19. **Screen 19 (القيادة التنفيذية والعناقيد السداسية)**: 6 عناقيد سداسية (Hex Pods) تغطي المؤشرات الحيوية التنفيذية مع شريط أحداث استخباراتية حية.
20. **Screen 20 (الحضور البشري والرفيق السيبراني JARVIS)**: مجسم الأفاتار البشري المضيء (Luminous Cybernetic Silhouette) بالنواة الصدرية المتوهجة والألياف العصبية وقناع العين التفاعلي ومحادثة صوتية وكتابية فورية.

## 4. شروط المطابقة والأداء
- نسبة المطابقة البصرية: 100% مع الملفات المرجعية في `public/images/neural-studio/`.
- معدل الإطارات: 60 FPS مستمر، مع استخدام CSS GPU Hardware Acceleration والـ WebGL الشفاف.
- دعم كامل للعربية والإنجليزية مع الحفاظ على التناسق المعماري للنظام.
- إمكانية تشغيل واستدعاء كافة خوادم MCP الـ 21 وأدواتها الـ 88 مباشرة من أي شاشة عبر واجهة موحدة.
