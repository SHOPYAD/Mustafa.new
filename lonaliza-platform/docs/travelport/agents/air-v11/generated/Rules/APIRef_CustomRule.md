See the POST request above for base path. Related Content: Booking Guide , Custom Rule List , Custom Rule Details Use Custom Rule to add or delete a custom rule to/from a booking. Send either request as part of a workbench session, either during the initial booking workflow after an offer is added, or a post-commit workbench for an existing reservation. The POST and DEL requests must be followed at some point by a workbench commit . If adding a rule, the commit compares the booking to the conditions in the attached rules. If any conditions are not met, an error message is returned and workbench changes are not committed. The workbench session is maintained to allow the conditions required by the attached rule to be corrected in the booking. Send the Custom Rule Delete request in any workbench session to delete one or all custom rules from a reservation. Custom rules are created in a rules booking engine used by your agency. See Custom Booking Rules in the Booking Guide for details. Note the following: The RuleRecordName parameter must send a rule name that has already been created and associated with your PCC. Otherwise, the error message&#160; INVALID&#160;-&#160;RULE&#160;{NAME}&#160;DOES&#160;NOT&#160;EXIST&#160;-&#160;CustomRule is returned. The exception is that you can send a rule name created for a PCC with which your PCC has an agreement by sending that PCC in the optional PCC query parameter. If your PCC does not have an agreement with that PCC, the error message NO&#160;AGREEMENT&#160;EXISTS&#160;FOR&#160;PSEUDO&#160;CITY&#160;-&#160;{PCC}&#160;-&#160;CustomRule is returned. You must send a separate request for each rule to add. You can add up to three custom rules to a booking. If additional rules are sent, the error message INVALID&#160;-&#160;THREE&#160;RULES&#160;ALREADY&#160;ATTACHED&#160;-&#160;CustomRule is returned. If you send a rule name that has already been attached to a booking, the error message RULE&#160;{NAME}&#160;ALREADY&#160;ATTACHED&#160;-&#160;CustomRule is returned. Request As part of the request requirements, also see Authentication and Common Air API Headers . Query Parameters Parameter Description Required/Optional RuleRecordName Use in the POST request to add the name of a custom rule associated with your PCC to the booking. You can send a Custom Rule List request to return a list of all rules associated with a specific PCC. You can add up to three custom rules to a booking; send a separate request for each rule. Required to add PCC Use in the POST request to add a custom rule associated with another PCC with which your PCC has a selective access agreement. Optional RuleRecordSequence Use in the DEL request to specify the sequence number of a single rule to remove from the booking, or all rules from the booking. Supported values: {sequence number} :&#160;Send up to three digits (001-999) to specify the rule record sequence of the rule to delete. You can send a Custom Rule List request to retrieve a list of all custom rules and their sequence numbers, or a reservation retrieve with detail view requested to see the rules attached to a booking. ALL:&#160;Send the value ALL to delete all custom rules for a booking. Required to delete Request Body There is no message payload. Response The POST response returns a standard system-generated identifier for the transaction. The DEL response does not return a payload.
