Fare Display API&#160;Reference Skip To Main Content Account Settings Logout placeholder Account Settings Logout Filter: All Files Submit Search Filter: All Files Submit Search Fare Display API&#160;Reference Request Response Example request Example response POST air/faredisplay/fares Base path: Pre-production https://api.pp.travelport.net/11/air/ Production https://api.travelport.net/11/air/ Related Content: Booking Guide , All Booking and Ticketing Workflows The Fare Display API&#160;returns all fares for the requested parameters, regardless of availability. This request does not require a preceding Search or AirPrice request. Fare displays are often useful for fare-driven travelers. To retrieve fare rules after a Fare Display response, use the Fare Rules API . GDS only; not supported for NDC. Request As part of the request requirements, also see Authentication and Common Air API Headers . Query Parameters None. Request Body Show Request Body Table Object Description Required/Optional FareDisplayQueryRequest Top level object. Required from Originating city or airport. Key value pair: value : IATA location code for originating location. Can be city or airport code. Required to Destination city or airport. Key value pair: value : IATA location code for destination location. Can be city or airport code. Required departureDate String. Date of departure in YYYY-MM-DD format (e.g., departureDate="2024-12-06"). Optional returnDate String. Date of return in YYYY-MM-DD format (e.g., departureDate="2024-12-06"). Optional carrier Array. Up to three IATA carrier codes to request the fares for. Optional fareDisplayModifiers Use to request fare display with a specific fare basis code. fareBasisCode : Fare basis code for the fare to display. Optional Response Show Response Body Table Object Description FareDisplayResponse Top level object. transactionId : System-generated unique ID for this response. Can be used for internal tracking and troubleshooting. traceId : Returned if a custom trace ID was sent in the request header. See Transaction and Trace IDs for details. See Identifiers in the JSON &#160;APIs for more about identifiers across all JSON &#160;APIs. Identifier Returns identifier for the entire response as a unique system-generated identifier in value . fareDisplay Top level object. Includes faresLastUpdated, to, from, departureDate, comment, fareType, listCurrency, and fare. faresLastUpdated Date of last update from ATPCO. from Originating city or airport. Key value pair: value: IATA location code for originating location. to Destination city or airport. Key value pair: value: IATA location code for destination location, departureDate String. Date of departure in YYYY-MM-DD format (e.g., departureDate="2022-12-06"). comment The text of the fare rule. fareType String. Indicates the fare type. Possible values are AirlinePrivateFare, AgencyPrivateFare, PublicFares, or NetFare. listCurrency String. The currency code for the currency fares are returned in. alternateCurrencyFares Currency code for any fares returned in an alternate currency. unsaleableFaresExistInd Returned only if true to indicate unsaleable fares may exist. fare Fare details for each flight on the details. Key value pairs: sequence : Segment sequence for this flight. carrier: Airline carrier. amount: &#160;Fare amount. roundTripInd: Returned only if true to indicate this is a round trip fare. oneWayInd: Returned only if true to indicate this is a one way fare. fareBasisCode: Fare basis code for the fare. bookingClass: Class of service for this fare; fare must be booked with this booking code to get this fare. advanceReservationRulesApply: Returned only if true to indicate fare has additional advance reservation rules not returned in this response. Seasons: Returned if a range of travel dates apply to fare: validFrom: Start of range in YYYY-MM-DD format. validTo: End of range in YYYY-MM-DD format. mileageBasedInd: Returned only if true to indicate fare is based on mileage. routingBasedInd: Returned only if true to indicate fare is based on route. globalIndicator: If applicable, returns an IATA-specified global indicator for the basic routing this fare applies to. privateFareInd: Returned only if true to indicate fare is private fare. timeOfDayRestrictionsExistInd: Returned only if true to indicate time restrictions apply to fare. dayOfWeekRestrictionsExistInd: Returned only if true to indicate day of the week restrictions apply to fare. firstTicketingDate: Returned to indicate first date a ticket can be issued for fare in YYYY-MM-DD format. lastTicketingDate: Returned to indicate last date a ticket can be issued for fare in YYYY-MM-DD format. additionalFaresExistInd: Returned only if true to indicate additional fares exist. moreRulesApplyInd: Returned only if true to indicate additional rules exist. May include AdvanceReservationPeriod, minimumStayOptions, maximumStayOptions objects. AdvanceReservationPeriod Returned if fare requires an advance purchase. Key value pairs: period: Number of units in advance of departure fare must be reserved. Unit: Time in which advance purchase in period is returned, such as Days or Months. minimumStayOptions Returned if a minimum stay applies to this fare. May be expressed as a day of week (SU), a number of days (6), or a number of months (12M). Key value pairs: type: Possible values: StayDayOfWeek, StayNumberOfDays, StayNumberOfMonths NumberOfMonths / NumberOfDays / DayOfWeek: Value for minimum stay type. maximumStayOptions Returned if a maximum stay applies to this fare. May be expressed as a day of week (SU), a number of days (6), or a number of months (12M). Key value pairs: type: Possible values: StayDayOfWeek, StayNumberOfDays, StayNumberOfMonths NumberOfMonths / NumberOfDays / DayOfWeek: Value for maximum stay type.
