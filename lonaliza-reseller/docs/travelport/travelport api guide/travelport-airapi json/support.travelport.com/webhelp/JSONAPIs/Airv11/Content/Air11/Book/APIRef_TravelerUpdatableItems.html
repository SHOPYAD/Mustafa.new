Traveler Updatable Items API Reference

RequestResponseExample requestExample response

POST

book/updatableItem/reservationworkbench/{workbenchID}/travelerupdatableitems/buildfromtraveler

For {workbenchID} send the workbench identifier returned in ReservationResponse/Identifer/value in the workbench create response.

Base path:

Pre-production https://api.pp.travelport.net/11/air/

Production https://api.travelport.net/11/air/

Related Content: Booking Guide, Traveler Modify Guide

Use the Updatable Items request to return a list of traveler information that can be updated. Updatable Items retrieves by one or more traveler IDs a list of objects that are updatable for that traveler/s, and returns for each an indicator for whether that item can be added, modified, or deleted. It is sent as part of a workbench session, either during the initial booking workflow or a post-commit workbench for an existing reservation. It is followed by a Traveler Update request to implement changes. 

See the Traveler Modify Guide for a list of supported changes.

Request

As part of the request requirements, also see Authentication and Common Air API Headers.

Query Parameters

None.

Request Body

Show Request Body Table

Object

Description

TravelerUpdatableItemsQueryBuildFromTraveler

Top level object.

Identifier

Array. Sends identifier/s as string/s for the traveler/s to retrieve a list of updatable items for.

After you establish a post-commit workbench session, send a request for updatable items with the traveler identifier for each traveler to update. You can request one or more travelers on the same reservation. If you need the traveler identifiers, retrieve the reservation before you create the workbench, or retrieve the workbench to get full reservation details.

The payload must send the traveler identifier for each passenger with information to update.

Response

Show Response Body Table

Object

Description

TravelerUpdatableItemsListResponse

Top level object.

Key value pairs:

transactionId: System-generated unique ID for this response. Can be used for internal tracking and troubleshooting.

traceId: Returned if a custom trace ID was sent in the request header. See Transaction and Trace IDs for details.

See Identifiers in the JSON APIs for more about identifiers across all JSON APIs.

Includes Identifier and TravelerUpdatableItemsID.

TravelerUpdatableItemsID

Key value pairs:

travelerIdentifier: Traveler identifier for traveler to which this updatable item applies.

id: Short id for TravelerUpdatableItemsID object.

Includes Identifier object.

TravelerUpdatableItemsID/Identifier

Returns an identifier for the TravelerUpdatableItemsID object in these key value pairs:

authority: Source of information.

value: Unique system-generated identifier.

TravelerUpdatableItem

Returns array of updatable objects with an @type value of TravelerUpdatableItem/{ItemName} per below; for example, TravelerUpdatableItemEmail.

@type value TravelerUpdatableItem{ObjectName}

Currently supported objects are:

TravelerUpdatableItemEmail

TravelerUpdatableItemTelephone

TravelerUpdatableItemAddress

TravelerUpdatableItemCustomerLoyalty

TravelerUpdatableItemTravelDocument

TravelerUpdatableItemPersonName

TravelerUpdatableItemComments

Object for the type of data supported for modification, deletion, or addition. Each supported object includes all of the following objects:

Identifier: Unique system-generated identifier for this data element; must be sent in any subsequent Traveler Update request to add, modify, or delete the data in this instance.

{action}Ind: Returns any of the following key value pairs that are true:

  • modifiableInd: true indicates currently existing data that can be modified on the booking.

  • deletableInd: true indicates currently existing data that can be deleted from the booking.

  • addableInd: true indicates this type of data can be added to the booking.

{CurrentData}: When data exists and is either modifiable or deletable, this object returns the current data in that object. Supported objects in the corresponding TravelerUpdatableItem{objectName} are:

Email

Telephone

Address

CustomerLoyalty

TravelDocument

PersonName

Comments

TravelerUpdatableItemsListResponse/Identifier

Unique system-generated identifier for this response as a whole. The value in Identifier/value must be sent in the endpoint for any subsequent Traveler Update request for the data in this response.

authority: Source of information.

value: Unique system-generated identifier.
