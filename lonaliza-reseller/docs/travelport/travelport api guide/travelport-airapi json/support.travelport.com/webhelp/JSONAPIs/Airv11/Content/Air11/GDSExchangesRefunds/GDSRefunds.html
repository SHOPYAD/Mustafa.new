GDS Automated Refunds

The Refund Quote and Cancel APIs support GDS automated refunds, which allow you to request a quote for the refund amount and any penalties and then issue the refund. By default the itinerary is canceled; however, you can retain the offer as a held booking for later ticketing.

Refund Support

You must be specifically provisioned for refunds through the JSON APIs. Contact your account representative with any questions.

Refunds are supported as follows:

  • Only voluntary refunds (passenger has requested the refund).
  • Refunds only to original form of payment (FOP).
  • Active reservation with active ticketed filed fare.
  • Public fares only.
  • Conjunction tickets.
  • Tickets with reservations created and ticketed at a United States (US) or India POS.
  • Wholly unflown domestic itineraries: No travel has taken place and the flight coupons are in OPEN status. Domestic travel here is defined as itineraries with all flights within India, or itineraries with all flights within the US.

Not supported for previously exchanged tickets, or tickets with multiple offers.

Refund Workflow

The GDS refunds process uses the following API requests.

Step #

Booking Workflow Step

Description and Notes

1

Post-Commit Workbench

Initiate a workbench for the existing booking.

2

Refund Quote

Determine what if any refund value may be available on the ticket.

A refund does not necessarily mean the passenger receives the full amount of the original ticket price. The airline may impose a cancellation penalty, and/or some taxes, fees, or charges may be non-refundable, depending on fare rules. The refundable amount is returned in Refund Quote.

Refund Quote price details in the following objects; all objects provide a total amount and a breakdown by base fare, price, and taxes as applicable:

  • Price: Amount paid for the ticket.

  • ModifyPrice: Any amount eligible for refund.

  • SupplierRetainedPrice: Any amount forfeited.

3

Cancel

Cancels the ticket and issues a refund. Optionally, you can choose to issue the refund but retain the offer as a held booking. Retaining the offer allows you to re-ticket that offer in a subsequent session using the regular ticketing workflow.

Refund Steps

Post-Commit Workbench API Reference

Start the refund process by initiating a post-commit workbench to create a session for the refund. Use the following endpoint.

There is no request message payload.

The response is the same as Reservation Retrieve response.

POST

book/session/reservationworkbench/buildfromlocator?Locator={LocatorCode}

For {LocatorCode} send the locator code returned at booking commit or in Reservation Retrieve in Receipt/Confirmation/Locator/value.

Base path:

Pre-production https://api.pp.travelport.net/11/air/

Production https://api.travelport.net/11/air/

Refund Quote API Reference

The Refund Quote API determines what if any refund value may be available on a ticket. Use the following endpoint.

POST

book/airoffer/reservationworkbench/{{workbenchID}/offers/canceloffer

For {workbenchID} send the workbench identifier returned in ReservationResponse/Identifer/value in the workbench create response.

Base path:

Pre-production https://api.pp.travelport.net/11/air/

Production https://api.travelport.net/11/air/

Query Parameters

None.

Send the message payload per below.

Response Payload

The response includes the following objects.

Show Response Body Table

Object

Description

OfferListResponse

Top level object.

Includes OfferID object.

OfferID

Returns details of potential refund. For GDS refunds returned with @type OfferModify.

Includes Identifier, ContentSource, Product, Price, TermsAndConditionsFull, ModifyPrice, SupplierRetainedPrice, ConsumedPrice.

Identifier

Offer identifier for the offer sent in request.

Key value pairs:

authority: Source of information.

value: Unique system-generated identifier.

ContentSource

Identifies type of content, for GDS refunds, this value is GDS.

Product

Standard Product object with flight details for the offer as ticketed. One instance for each leg of the itinerary. See Reservation Retrieve for details.

Price

Returns the amounts paid for the ticket.

Standard Price object with CurrencyCode, Base, TotalTaxes, TotalFees, TotalPrice (the total amount paid for the ticket), PriceBreakdown objects. See Reservation Retrieve for details.

CurrencyCode

The currency of the amounts. Key value pairs:

value: String. Currency code.

Base

Number. The base amount of the price paid not including taxes and fees.

TotalTaxes

Number. Total of any taxes paid.

TotalFees

Number. Total of any fees paid.

TotalPrice

Number. Total amount paid for the ticket including base, taxes and fees.

PriceBreakdown

Array. Standard PriceBreakdown object to return detailed taxes and fees. See Reservation Retrieve for details.

TermsAndConditionsFull

TermsAndConditionsFull object with terms and conditions of the refund.

Includes ExpiryDate and FareGuaranteePolicy.

ExpiryDate

The time the refund code expires, generally 30 minutes from workbench creation. If the refund code expires the workflow must be re-initiated.

FareGuaranteePolicy

Travelport's fare guarantee policy for the offer.

EligibleforADMReview

String. Returned with a value of Yes when the refund is eligible for an airline agency debit memo (ADM) review, which is the process where travel agencies dispute or validate financial penalties.

Code

Key value pair:

value: String. Always returns G for guaranteed.

ModifyPrice

Returns the amounts eligible for refund.

Standard Price object with CurrencyCode, Base, TotalTaxes, TotalFees, TotalPrice (the total amount eligible for refund), PriceBreakdown objects. See Reservation Retrieve for details.

SupplierRetainedPrice

Returns the amounts that are not eligible for refund.

Standard Price object with CurrencyCode, Base, TotalTaxes, TotalFees, TotalPrice (the total amount that will not be refunded), PriceBreakdown objects. See Reservation Retrieve for details.

ConsumedPrice

Reserved for future use. Always returns zero amounts in same format as standard Price object.

Cancel API Reference

The Cancel API is used instead of the standard workbench commit to complete the GDS refund workflow. Use the following endpoint. There is no message request body.

POST

receipt/reservations/{workbenchID}/receipts?OfferIdentifier={OfferID}

For {workbenchID} send the workbench identifier returned in ReservationResponse/Identifer/value in the workbench create response.

For {OfferID} send the offer identifier from Offer/Identifier/value in the Create Workbench response.

Base path:

Pre-production https://api.pp.travelport.net/11/air/

Production https://api.travelport.net/11/air/

Header Parameters

Parameter

Description

Required/Optional

RetainFlag

Boolean. Determines the type of cancel operation. Supported values:

false: Default. Cancels the offer and issues a refund based on fare rules.

true: Retains the offer as a held booking and issues a refund based on fare rules.

Required

Response Payload

Show Response Body Table

Object

Description

ReceiptListResponse

Top level object for response. Key value pairs:

transactionId: System-generated unique ID for this response. Can be used for internal tracking and troubleshooting.

traceId: Returned if a custom trace ID was sent in the request header. See Transaction and Trace IDs for details.

See Identifiers in the JSON APIs for more about identifiers across all JSON APIs.

Includes ReceiptID and ReferenceList objects.

ReceiptID

Top level object for refund details. Returns ReceiptID with @type ReceiptPayment with cancellation details.

If the offer was retained (per the RetainFlag header parameter setting in the request), also returns an instance of ReceiptID with @type ReceiptCancellation with the locator code for the held booking.

Includes Identifier, OfferRef, and Document.

Identifier

Standard identifier object with authority and value.

OfferRef

String array. Cross-reference number for details of the offer (either canceled or retained) as returned in ReferenceList/Offer/id.

Document

Array. Returns ticket and cancellation details. The @type value DocumentTicketRefund indicates a refund was issued.

Includes Number, TravelerIdentifierRef, Amount, SupplierRetainedPrice, ConsumedPrice, FareGuaranteePolicy.

Number

String. Ticket number of the canceled ticket.

TravelerIdentifierRef

Key value pair:

passengerTypeCode: String. The PTC of the traveler.

Amount

Price details for the amount refunded. Includes CurrencyCode, Base, Taxes, Total objects.

CurrencyCode

Key value pair:

value: String. Currency code of the amounts.

Base

Number. The base amount of the refund.

Taxes

Tax amounts refunded. Objects returned may vary; typically includes TotalTaxes.

Total

Number. Total amount refunded.

SupplierRetainedPrice

Any amounts that were not refunded. Returns amounts in the CurrencyCode, Base, TotalTaxes, TotalPrice, and PriceBreakdown in the same format per above and in the standard Price object.

Any amount in SupplierRetainedPrice/TotalPrice is the total amount that was not refunded.

ConsumedPrice

Reserved for future use. Always returns zero amounts in the CurrencyCode, Base, TotalTaxes, TotalPrice, and PriceBreakdown in the same format as the standard Price object.

FareGuaranteePolicy

Travelport's fare guarantee policy for the offer. Key value pair:

passengerTypeCodes: String. The PTC/s of the traveler/s.

Includes EligibleforADMReview and Code.

EligibleforADMReview

String. Returned with a value of Yes when the refund is eligible for an airline agency debit memo (ADM) review, which is the process where travel agencies dispute or validate financial penalties.

Code

Key value pair:

value: String. Always returns G for guaranteed.

ReferenceList

Top level object.

Includes @type ReferenceListOffer/Offer and @type ReferenceListTraveler/Traveler.

Offer

Details for the refunded offer. Key value pair:

id: Internal offer id used for cross-reference.

Includes Identifier, Product, Price, and TermsAndConditionsFull objects.

Identifier

Standard identifier object with authority and value.

Product

Array. Standard Product object with flight details. One instance returned for each leg of the itinerary. See Reservation Retrieve for details.

Price

Standard Price object with price details for the offer. See Reservation Retrieve for details.

If the number in Price/TotalPrice matches the number returned in ReceiptID/Document/Amount/Total, a full refund was issued.

TermsAndConditionsFull

Standard TermsAndConditionsFull object with terms and conditions of the offer. See Reservation Retrieve for details.

Traveler

Traveler details. Specific objects returned vary according to the traveler details on the booking but generally include id, Identifier, PersonName, Telephone, and TravelDocument. See Reservation Retrieve for details.
