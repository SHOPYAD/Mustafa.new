Air Availability API Reference

RequestResponseExample requestExample response

POST

search/airAvailability

Base path:

Pre-production https://api.pp.travelport.net/11/air/

Production https://api.travelport.net/11/air/

Related Content: Air Search Guide

Air Availability returns scheduled flights between a specified city pair on a specified day and time and indicates whether seats are available on those flights. Air Availability is a full payload request that focuses on seat availability by class of service. It does not return pricing information.

GDS only; not supported for NDC.

Request

As part of the request requirements, also see Authentication and Common Air API Headers.

Query Parameters

None.

CatalogProductOfferingsRequest

Top level object with @type CatalogProductOfferingsRequestAir.

Includes PassengerCriteria and SearchCriteriaFlight objects. May contain SearchModifiersAir.

Required

PassengerCriteria

Array. Defines the type of passenger to search for. Optional - sending PTC details does not change the response.

Send one PassengerCriteria for each passenger type code (PTC).

Availability supports the following:

  • Up to nine total passengers across all PTCs
  • Maximum of six PTCs
  • Maximum of six O&D pairs

Optional

passengerTypeCode

String. The passenger type code for the passengers on the itinerary. Common PTCs are:

  • ADT: adult
  • CHD: child of unknown age
  • CNN: child when age is known
  • INF: infant without a seat
  • INS: infant with a seat
  • UNN: unaccompanied child

See the Downloads page to download a full list of PTCs.

Optional

number

Number. The number of passengers with this PTC.

Optional

SearchCriteriaFlight

 

Array. Each instance defines one leg of the itinerary by specifying an origin and destination (O&D) pair, aka departure and arrival location, for that leg.

Includes From and To objects.

Required

departureDate

String. Date of departure in YYYY-MM-DD format (e.g., departureDate="2026-12-06").

Required

departureTime

String. Optional to send a time to search for flights departing close to that specified time. HH:MM:SS format (e.g., departureTime="18:00:00").

Sending "00:00:00" is not supported and causes an error message.

Optional

arrivalDate

String. Local date of arrival in YYYY-MM-DD format (e.g., departureDate="2026-12-06").

Cannot be used with departureDate. If sent with a departureDate, the departureDate is ignored. Best practice when sending an arrival date is to also send an arrival time.

Optional

arrivalTime

String. Optional to send a local time of arrival to search for flights arriving close to that specified time. HH:MM:SS format (e.g., departureTime="18:00:00").

Cannot be used with departureTime.

Sending "00:00:00" is not supported and causes an error message.

Optional

From

Object.

Required

value

 String. The IATA airport or city code for the departure airport/city for this leg.

Required

cityOrAirport

String. Optional enumeration specifying whether to restrict the search based on the city/airport code sent in value. Supported value:

  • City or Airport
cityOrAirport Options Behavior

Airport code with no cityOrAirport value

Expands the availability selection to the city while giving preference to the requested airport. For example, LGA would return flights for LGA, EWR, and JFK but would target more content from LGA.

City code with no cityOrAirport value, or with City or Airportvalue

Returns an unweighted selection of inventory for all airports in the city. For example, NYC would search content equally between LGA, EWR, and JFK.

Optional

To

Object

Required

value

 String. The IATA location code for the arrival city/airport for this leg.

Required

cityOrAirport

String. Optional enumeration specifying whether to restrict the search based on the city/airport code sent in value. Supported value:

  • City or Airport

See cityOrAirport above for behavior.

Optional

SearchModifiersAir

Optional search modifiers. Can include ConnectionPreferences and/or CarrierPreference.

Optional

CarrierPreference

Array. Specify preference for a permitted airline to limit results to one or more carriers.

Optional

preferenceType

String. The type of carrier preference. Availability supports only the following:

  • Permitted: Returns only results on the specified carrier or carriers. Returns an error if the carrier/s do not have availability within the requested search parameters.

Required

carriers

 String. One or more carrier codes to permit.

Required

ConnectionPreferences

Specify whether results must have one or more of the specified connection points (permitted), or if they cannot have one or more of the specified connection points (prohibited).

Optional

cityOrAirport

String. Optional enumeration specifying whether to restrict the search based on the city/airport code sent in value. Supported value:

  • City or Airport

See cityOrAirport above for behavior.

Optional

legSequence

Use to apply preference to only specific legs of the itinerary. Do not send if requesting preference at itinerary level.

Optional

preferenceType

String. The type of connection preference. Supported values are:

  • Permitted: Returns only results that connect through one or more of the specified locations in ConnectionPoint. Returns error if there is no availability through the specified connecting location/s.
  • Prohibited: Excludes results that connect through one or more of the specified locations in ConnectionPoint.

Only one preference type can be requested for an O&D pair, either Permitted or Prohibited but not both.

Required

ConnectionPoint

 String. Three-letter IATA code for the connecting location/s for this preference. For example, if you specify three locations, any flights meeting any one or more of those locations will be permitted or prohibited per the specified preferenceType.

Required

 

Response

The Air Availability response shares the basic structure of the Search response but returns a subset of its objects. It does not return any pricing or brand information. The tables in this section break down the Air Availability response into several of its objects to list all information in each.

Object Description  

ReferenceList

Top level object for the consolidated flight, product, terms and conditions, and brand information referenced in the offers in CatalogProductOfferings.

Returns one instance each of types ReferenceListFlight and ReferenceListProduct.

  

ReferenceList/ReferenceListFlight

Object Description

ReferenceListFlight

Returns an array of Flight objects that match to the flights that make up a product.

Flight

Array. One instance for one flight.

Key value pairs:

distance: Distance covered by the flight.

duration: Time of the flight in hours (H) and minutes (M).

carrier: Airline carrier.

number: Flight number.

operatingCarrier: When the carrier has filed a codeshare operating carrier for the flight, the IATA code for that codeshare carrier.

operatingCarrierName: Name of the marketing operating carrier.

equipment: Equipment model. Note that TRN, TRS, and BUS equipment codes indicate ground transportation.

stops: For a direct flight that makes one or more stops between an origin and destination, the number of stops.

id: Internal flight reference id, used to match this flight to the flights listed in each offer (CatalogProductOffering).

Includes Departure, Arrival, AvailabilitySourceCode objects.

Departure

Departure details. Key value pairs are the location, date, time, and terminal of departure.

Arrival

Arrival details. Key value pairs are the location, date, time, and terminal of arrival.

AvailabilitySourceCode

Returned to assist in troubleshooting. Recommended to be sent in the AirPrice Full Payload and Add Offer Full Payload requests.

GDS only; not supported for NDC.

Supported values and definitions for AvailabilitySourceCode:

  • A: AVS (availability and schedules)
  • B: Travelport cache
  • C: AVS
  • D: Direct Access
  • E: Travelport cache
  • F: Travelport cache
  • G: Travelport cache
  • H: Travelport cache
  • I: Travelport cache
  • K: Travelport cache
  • L: Last seat availability
  • M: Unknown source
  • O: Travelport cache
  • P: Travelport cache
  • Q: Travelport cache
  • S: Seamless
  • T: Travelport cache
  • U: Unknown source
  • X: Customer reusing availability data from customer cache (data originally obtained from Travelport)
  • Y: Customer reusing data obtained from another system (e.g., another GDS) (data may be fresh or stored in customer cache)
  • Z: Customer sold from e-streamed data stored in customer cache

 

ReferenceList/ReferenceListProduct
Object Description

ReferenceListProduct

Returns details for the products returned in offers. Includes the Product object.

Product

Array. One instance for each product id.

Key value pairs:

totalDuration: Total time length of the segment in hours (H) and minutes (M).

id: Product id.

Includes FlightSegment and PassengerFlight objects.

FlightSegment

Array. One instance for each flight segment in the product.

Key value pairs:

sequence: Order of the sequence; e.g. 1 for the first segment on the leg.

operationalStatus: Operational status of this flight. Possible values are FlightBoarding, FlightCancelled, FlightDeparted, FlightPastScheduledDeparture, NotAvailableUseSearch (may be returned if no classes of service are returned for a flight, or when the flight status is unknown).

Includes Flight object.

Flight

Array. One instance for each flight in the product.

Includes id.

id

Unique identifier for this flight. Matches to identifier in ReferenceListFlight/Flight.

PassengerFlight

Returns availability details for each class of service on this flight.

Includes the FlightProduct object.

FlightProduct

Details for this flight.

Key value pairs:

segmentSequence: Order of this flight in the sequence.

cabin: Cabin class.

ClassOfServiceAvailability

Defines the class of service, the number of seats available for the class of service, and the status of the class of service (E.g., Available).

Key value pairs:

number: Number of seats available for the class of service.

status: Status of these seats, such as Available. If no seats available for a class of service, possible values are Not Available, Request, Waitlist, Waitlist Closed.

value: Class of service code.

Example Request

For additional examples, download the developer toolkits and see Using Postman and Developer Toolkits.

The following example request is for a round trip itinerary with the optional ConnectionPreference modifier.

Show Example Request for round-trip with optional modifiers 
{
    "CatalogProductOfferingsQueryRequest": {
        "CatalogProductOfferingsRequest": {
            "@type": "CatalogProductOfferingsRequestAir",
            "PassengerCriteria": [
                {
                    "number": 1,
                    "passengerTypeCode": "ADT"
                }
            ],
            "SearchCriteriaFlight": [
                {
                    "departureDate": "2024-05-19",
                    "From": {
                        "value": "LAX"
                    },
                    "To": {
                        "value": "JNB"
                    }
                },
                {
                    "arrivalDate": "2024-05-29",
                    "From": {
                        "value": "JNB"
                    },
                    "To": {
                        "value": "LAX"
                    }
                }
            ],
            "SearchModifiersAir": {
                "ConnectionPreferences": [
                    {
                        "preferenceType": "Permitted",
                        "legSequence": [
                            1
                        ],
                        "ConnectionPoint": [
                            "AMS"
                        ]
                    },
                    {
                        "preferenceType": "Prohibited",
                        "legSequence": [
                            2
                        ],
                        "ConnectionPoint": [
                            "FRA"
                        ]
                    }
                ]
            }
        }
    }
}
