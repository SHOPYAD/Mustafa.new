Travel Agency Details API Reference (Single Payload)

RequestResponseExample requestExample response

POST

ticket/travelagency/reservationworkbench/{workbenchID}/travelagency

For {workbenchID} send the workbench identifier returned in ReservationResponse/Identifer/value in the workbench create response.

Base path:

Pre-production https://api.pp.travelport.net/11/air/

Production https://api.travelport.net/11/air/

Related Content: Booking Guide

Use Travel Agency Details to add a travel agency corporate ID and details including address, telephone, and email to a booking. Must be sent as part of a workbench session, either during the initial booking workflow or a post-commit workbench for an existing booking, and followed by a workbench commit.

The reservation retrieve for a booking returns any travel agency details associated with that booking.

To update and delete this information, use the Travel Agency Corporate ID, Travel Agency Address, Travel Agency Email, and Travel Agency Telephone APIs.

Request

As part of the request requirements, also see Authentication and Common Air API Headers.

Query Parameters

None.

Required/Optional

TravelAgencyQueryTravelAgencyWrapper

Top-level object.

Includes TravelAgencyQueryTravelAgency object.

Although all objects here are listed as optional, at least one object must be populated or an error message is returned. Only one address, email and/or corporate ID is allowed; multiple telephone numbers can be sent.

Required

TravelAgencyQueryTravelAgency

Top-level object.

Includes Address and CorporateCode objects. No objects are specifically required to be sent, but either Address or CorporateCode must be populated to avoid an error.

Includes AddressLine, City, StateProv, Country, PostalCode, and Addressee objects.

Response

The response returns the details sent in the request. Objects returned vary per the request.

Show Response Body Table

Object

Description

TravelAgencyResponse

Top level object.

Includes TravelAgency object.

TravelAgency

Top level object for travel agency ID and response identifier. Any corporate code is not returned in the response but is returned in any subsequent Reservation Retrieve.

Key value pair:

id: System-generated id for this travel agency. Must be sent in any subsequent requests to modify or delete any travel agency details.

Includes Identifier object.

Identifier

System-generated identifier for the response. Key value pairs:

authority: Source of information.

value: Unique system-generated identifier.

Telephone

Array. One instance for each telephone number for the agency. Telephone details are not returned in the response but are returned in any subsequent Reservation Retrieve.

id: System-assigned travel agency telephone id. Must be sent in any subsequent telephone update or delete request.

Address

Identifier for the travel agency address, if address was sent in the request. Address details are not returned in the response but are returned in any subsequent Reservation Retrieve.

id: System-assigned travel agency address id. Must be sent in any subsequent address update or delete request.

Email

Id for the email sent in details request. Email details are not returned in the response but are returned in any subsequent Reservation Retrieve.

Key value pair:

id: Travel agency email id. Must be sent in any subsequent email update or delete request.

The following example Travel Agency Details request sends an agency address, corporate code, telephone, and email to add to the booking in the workbench.

{
 "TravelAgencyQueryTravelAgencyWrapper": {
  "TravelAgencyQueryTravelAgency": {
   "Address": {
    "AddressLine": "28 BROAD STREET",
    "City": "ENGLEWOOD",
    "StateProv": {
     "name": "COLORADO"

     "name": "US"
    },

     "countryAccessCode": "1",
